# poi-plugin-battle-sim

一個 [poi](https://github.com/poooi/poi) 插件，用來估算艦隊在某張地圖上的表現。它先用 [compass](https://x-20a.github.io/compass/) 預測艦隊可能走的路線，再用 [kancolle-fleet-optimizer](https://github.com/momocow/kancolle-fleet-optimizer) 對每條能抵達 BOSS 的路線進行蒙地卡羅戰鬥模擬。

## 使用方式

1. 選擇艦隊（第 1–4 艦隊）與地圖：一般海域（1–7 海域），或活動期間的活動海域。若該地圖有可自選的分歧或階段，也一併選擇。
2. 選擇模擬次數：快速（500）、一般（2000）、精確（10000）或自訂。
3. 按下 **Simulate**，或直接編輯艦隊（見[自動執行](#自動執行)）。

每次執行會擷取艦隊快照、預測路線，並模擬每條能抵達 BOSS 的路線。摘要會顯示每次出擊取得 S 勝、A 勝以上、B 勝以上的機率，以及抵達 BOSS 的機率與 BOSS 擊沉率，全部依路線機率加權。下方每條路線各有一張卡片，顯示該路線的機率、經過的節點與結果。執行後若更改了輸入，結果會變暗，直到再次執行為止。

面板文字支援英文、日文與繁體中文。艦船、裝備與地圖名稱依照 poi 的語言設定顯示。

### 自動執行

以下任一項變更時，會自動開始執行：

- 選擇的艦隊；
- 所選艦隊中的艦船（加入、移除、移動、交換或改造）；
- 這些艦船上的裝備（裝上、卸下、移動或改修）；
- 選擇的地圖；
- 分歧或階段的選擇；
- 活動海域的難度、血條或血條狀態（遊戲中的變化或改選）；
- 模擬次數。

只有在艦隊中每艘艦船的主裝備欄都已裝滿時才會自動執行。補強增設欄不計入，艦隊也不必滿編。在此之前 **Auto** 開關會轉為橘色，提示自動執行已暫停，**Simulate** 也會恢復為主要按鈕。HP、士氣、等級與熟練度的變化不會觸發執行，因此出擊歸來也不會。變更停止片刻後才會開始執行，所以輸入自訂模擬次數時只會執行一次。若執行途中艦隊有變動，該次執行會被取消並重新開始。可用 **Simulate** 旁的 **Auto** 開關關閉此功能，設定會被記住。

### 逐點設定

每個有戰鬥的節點都有各自的陣形與夜戰設定。陣形預設依節點類型決定，依序套用第一條符合的規則：

1. 該節點所有敵方編成都只有潛艇：單橫陣；
2. 有任一敵方編成含潛艇：梯形陣；
3. 夜戰節點：梯形陣；
4. 航空戰或空襲節點：輪型陣；
5. 其餘：單縱陣。

夜戰可設為 **如果為目標點**（預設，只在目標點追擊夜戰）、**總是** 或 **絕不**。夜戰節點固定為總是，空襲節點沒有夜戰。

地圖的敵方資料下載後，目標列會出現 **逐點設定** 按鈕。按下後會列出該地圖所有有戰鬥的節點、其預設陣形的理由，並可逐一改選陣形與夜戰；設定依地圖記住。關閉視窗時若有變更，會立即執行一次模擬。艦隊艦數不足以使用的陣形會反灰（少於 4 艘只能用單縱陣；輪型陣需要 5 艘）。

### 活動海域

活動期間，地圖選單會在 7 海域之後列出當期活動的海域，例如「62-3 (E-3) …」。目標列會多出 **難度**、**血條** 與 **血條狀態**（削血、斬殺、已攻略）三個選單，預設皆為 **依遊戲**，即 poi 讀到的目前狀態；也可逐圖改選，試算其他難度或階段，設定依地圖記住。出擊中一律依遊戲狀態。這三項決定讀取哪一組 kcnav 敵方資料，並套用該海域的特效。目前只支援可用單一艦隊出擊的海域；只能以聯合艦隊出擊的海域會顯示尚未支援。

### 遊戲資料包

地圖分歧、BOSS 節點、敵艦與海域特效、kcnav 敵方資料等經常變動的資料，放在獨立發布的遊戲資料包 `poi-plugin-battle-sim-data`（本 repo 的 [`fcd/`](fcd/README.md)），而不是寫在插件裡。插件內附一個版本，可離線使用；執行期間每 6 小時（以及載入時）會向 npm 檢查同主版本的新版。有新版時，頁尾右側會出現下載圖示並自動開啟提示，按 **更新** 才會下載、驗證並自下一次模擬起使用；按 **稍後** 則保留圖示。新活動因此只需發布新的資料包，不必更新插件。

kcnav 敵方資料以資料包的快照為主，玩家不必各自向 kcnav 下載；只有快照沒涵蓋的海域或活動組合，才會在第一次執行時下載一次。

### 自動切換

進入改裝畫面，或在遊戲中變更任一艦隊的艦船或裝備時，poi 會自動切換到本插件的分頁，讓自動執行的結果出現在眼前。可在 poi 的插件設定中，取消勾選本插件的「啟用自動切換」來關閉此功能；poi 的全域自動切換設定也同樣適用。

### 限制

- 尚未支援聯合艦隊（見 `openspec/changes/add-combined-fleet-support`）。
- 活動海域只支援單一艦隊；不支援友軍、支援艦隊與遊擊部隊。
- 內附的 optimizer 執行檔支援 macOS（`darwin-arm64`、`darwin-x64`）、Windows（`win32-x64`）與 Linux（`linux-x64`、`linux-arm64`，需 glibc 2.35 以上）。
- 路線預測需要能連線到 compass。資料包沒涵蓋的海域，第一次執行時會下載該海域的敵方資料。
